# One-shot cloud motion proof

This public repository contains only an original abstract test image generated
on a GitHub Linux runner. Its one-shot workflow requests a five-second
image-to-video sample from the creator-run Lightricks LTX 0.9.8 ZeroGPU Space.
It has no Devkatha production assets, credentials, publishing permissions, or
approval. A returned clip is a technical candidate only; inspect it at normal
speed before drawing any quality conclusion. The model license requires an
intelligible AI-generation disclosure for published output and separate terms
for entities with at least $10 million annual revenue.

The workflow reserves a permanent Git tag before one anonymous free request.
It never retries that tag or calls a billed inference API. An Actions artifact
contains the synthetic source, a bounded receipt, and the exact MP4 only if
the provider returned and it decoded. Its public visibility is intentional:
there are no private user images or scripts in this proof.
